================================================================================
1. GET ALL HOTEL BOOKINGS (Unpaginated)
================================================================================
Method:    GET
Endpoint:  /api/hotel-booking
Headers:
  Content-Type: application/json

Optional Query Parameters:
--------------------------------------------------------------------------------
  Parameter   | Type   | Description
  ------------|--------|--------------------------------------------------------
  status      | String | Filter by status: "Pending" | "Booked" | "Canceled"
  search      | String | Search keyword (matches guest first name, last name, or hotel name)
  userId      | Number | Filter bookings made by a specific registered User ID
  hotelId     | String | Filter bookings for a specific Hotel UUID

Example Request URLs:
--------------------------------------------------------------------------------
  1. Get All Hotel Bookings (Unpaginated):
     GET http://localhost:5000/api/hotel-booking

  2. Filter by Status:
     GET http://localhost:5000/api/hotel-booking?status=Pending

  3. Search by Guest Name / Hotel Name:
     GET http://localhost:5000/api/hotel-booking?search=Kumar

  4. Filter by Registered User ID:
     GET http://localhost:5000/api/hotel-booking?userId=1

  5. Filter by Hotel UUID:
     GET http://localhost:5000/api/hotel-booking?hotelId=b231b043-5e73-4671-b7ff-31c664df6c2f
