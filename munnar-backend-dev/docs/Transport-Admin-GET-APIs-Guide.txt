EXPLORING MUNNAR - TRANSPORT ADMIN GET APIs (UNPAGINATED FOR DASHBOARD)
================================================================================

Base URL (Local):  http://localhost:5000
Base URL (Prod):   https://your-render-service.onrender.com

Note: All the endpoints below return the COMPLETE data array without pagination
specifically designed for your Admin Dashboard tables, status counters, and charts.

1. CAR / CAB BOOKINGS APIs
================================================================================

A. GET ALL CAB BOOKINGS (Unpaginated)
--------------------------------------------------------------------------------
Method:    GET
Endpoint:  /api/cab-booking
Headers:   Content-Type: application/json

Optional Query Parameters:
  ?status=Pending       -> Filter by status ("Pending" | "Booked" | "Canceled")
  &search=Airport       -> Search across guest name, user name, pickup or drop point

Example Requests:
  GET http://localhost:5000/api/cab-booking
  GET http://localhost:5000/api/cab-booking?status=Pending
  GET http://localhost:5000/api/cab-booking?search=Laxman
